# Blocked Leverage Score Sampling in CP Tensor Decomposition

This repository contains Julia code for the numerical experiments associated with the manuscript **“Blocked Leverage Score Sampling in the Randomized Alternating Least Squares CP Tensor Decomposition.”**

The experiments compare **regular leverage-score sampling** and **blocked leverage-score sampling** for randomized alternating least squares (ALS) applied to the canonical polyadic decomposition (CPD) of tensors.

The implementation uses the [`ITensorCPD.jl`](https://github.com/kmp5VT/ITensorCPD.jl) package together with [`ITensors.jl`](https://github.com/ITensor/ITensors.jl).

The **blocked leverage-score sampling** algorithm is implemented in [`ITensorCPD.jl`](https://github.com/kmp5VT/ITensorCPD.jl) through [`BlockLevScoreSampled`](https://github.com/kmp5VT/ITensorCPD.jl/blob/main/src/algorithms/als_algorithms/randomized/krp_lev_score_sampled.jl).

## Requirements

The experiments are implemented in Julia and require the following packages:

- `ITensorCPD`
- `ITensors`
- `MAT`
- `Plots`

The package dependencies used by this repository are listed in `Project.toml`.

The experiments in this repository were developed using **ITensorCPD v0.0.82**, including the blocked leverage-score sampling implementation `BlockLevScoreSampled`.

Clone the repository and open the project directory in Julia or VS Code.

## Fit

The CPD fit reported in the experiments is

```text
fit = 1 - ||X - X_hat|| / ||X||
```

where `X` is the target tensor and `X_hat` is its CP approximation.

A larger fit indicates a more accurate approximation.

The fit computation used by the experiment scripts is implemented in

```text
src/blocked_cpd.jl
```

and follows the fit calculation used in the ITensorCPD development/test environment.

## Reproducibility

The same random seed is used for the regular and blocked experiments:

```julia
seed = 1234
```

Before constructing each initial CP decomposition, the random-number generator is reset using

```julia
rng = MersenneTwister(seed)
```

so that the regular and blocked methods begin from the same random CP initialization.

The experiment parameters are specified explicitly in each dataset-specific script.

Runtime and memory measurements may vary depending on hardware, Julia version, operating system, compilation state, and other processes running on the system.
